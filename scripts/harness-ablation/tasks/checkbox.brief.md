Build a `Checkbox` component for the component library in this repository.

A checkbox is a single on/off choice with a visible text label, used in settings forms such as notification preferences. Clicking the label toggles it, the same as clicking the box. It can start checked, be driven by the app, which needs to know when it changes, and be disabled while checked or unchecked. It has to work inside an ordinary HTML form.

The design is in `reference.png` at the repository root.

Deliverables:
- `packages/components/src/components/Checkbox/index.tsx`
- `packages/components/src/components/Checkbox/Checkbox.module.css`
- `packages/components/src/components/Checkbox/Checkbox.stories.tsx`
- Export the component and its public types from `packages/components/src/index.ts`.
